# Ganesh Furniture & Electronics

## 📌 Project Overview

Ganesh Furniture & Electronics is a Full Stack E-Commerce web application built using Java Spring Boot and React.

The goal of this project is to create a production-ready online shopping platform where customers can browse furniture and electronics products, add them to the cart, and place orders. An admin dashboard will allow management of products, customers, and orders.
